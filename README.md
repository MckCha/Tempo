# Tempo 

Tempo is a modular travel planning backend with an AI agent for itinerary ideation and messaging.

## Installation

```bash
cd backend
npm install
```

## Run
```bash
cd backend
npm run dev
```

## Ai Agent
```bash
cd ai-agent
python -m venv .venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
